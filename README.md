# دیار AI

پلتفرم هوش مصنوعی برای جست‌وجوی ملک، ارزیابی قیمت و مشاوره‌ی ویزا/مهاجرت در دبی.

- **بک‌اند زنده:** [diyar-ai-backend.onrender.com/docs](https://diyar-ai-backend.onrender.com/docs)
- **ریپو:** [github.com/amirhosseinp8010/diyar_ai](https://github.com/amirhosseinp8010/diyar_ai)
- **دموی فرانت‌اند:** لینک آرتیفکت Claude (تو چت)

نکته: پلن رایگان Render بعد از چند دقیقه بی‌فعالیتی می‌خوابه؛ اولین درخواست بعد از خواب چند ثانیه طول می‌کشه تا بیدار بشه.

## ساختار پروژه

```
diyar-ai/
├── backend/          بک‌اند واقعی FastAPI — جست‌وجوی ملک، ارزیابی قیمت، مشاور ویزا
│   ├── main.py
│   ├── visa_rules.py       منبع حقیقتِ آستانه‌های ویزا (جدول قانونمند)
│   ├── data/properties.json   ۱۸ تراکنش واقعیِ ثبت‌شده در DLD (اسنپ‌شات ۲۱ سپتامبر ۲۰۲۶)
│   ├── requirements.txt
│   └── Dockerfile
├── frontend/          دموی تعاملی HTML (همون آرتیفکت‌هایی که تو چت دیدی)
│   ├── index.html          دموی اصلی + پیچ‌دک داستانی
│   └── architecture.html   سند معماری فنی
└── render.yaml         تنظیمات دیپلوی رایگان روی Render
```

وضعیت واقعی الان: بک‌اند تست شده (۱۱ تست خودکار pass) و کار می‌کنه. فرانت‌اند به بک‌اند وصله (با fallback امن به داده‌ی نمونه اگه بک‌اند در دسترس نباشه) و دوزبانه‌ست (فارسی/English، دکمه‌ی تعویض بالای صفحه).

## اجرای محلی بک‌اند

```bash
cd backend
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/uvicorn main:app --reload
```

بعد مرورگر رو باز کن روی `http://127.0.0.1:8000/docs` — یه رابط Swagger کامل می‌بینی که می‌تونی مستقیم اندپوینت‌ها رو تست کنی. همین صفحه رو می‌تونی به سرمایه‌گذار هم نشون بدی: یه API واقعیه، نه فقط عکس.

## دیپلوی رایگان (بدون نیاز به کارت اعتباری)

۱. یه اکانت رایگان روی [render.com](https://render.com) بساز (با ایمیل یا گیت‌هاب).
۲. این پوشه رو به یه ریپازیتوری گیت‌هاب پوش کن:
   ```bash
   cd /Users/amir/diyar-ai
   git init
   git add backend render.yaml .gitignore
   git commit -m "Initial commit: Diyar AI backend"
   ```
   بعد یه ریپو خالی روی [github.com/new](https://github.com/new) بساز و طبق راهنمای خودش `git remote add` و `git push` کن.
۳. تو Render: **New → Blueprint** → ریپوی گیت‌هابت رو انتخاب کن. Render خودش فایل `render.yaml` رو پیدا می‌کنه و پلن رایگان رو پیشنهاد می‌ده.
۴. بعد از دیپلوی، یه آدرس مثل `https://diyar-ai-backend.onrender.com` می‌گیری. `/docs` همون‌جا هم در دسترسه.

نکته: پلن رایگان Render بعد از چند دقیقه بی‌فعالیتی می‌خوابه و درخواست اول کمی کند جواب می‌ده — برای دمو دادن زنده به سرمایه‌گذار، چند دقیقه قبلش یه بار بازش کن که بیدار بشه.

بعد از دیپلوی روی Render، فقط کافیه تو `index.html` مقدار `API_BASE` رو به آدرس واقعی‌ات تغییر بدی (یا از کنسول مرورگر `window.DIYAR_API_BASE` رو قبل از لود صفحه ست کنی).

## افزودن یا آپدیت‌کردن ملک‌های واقعی

دیتاست فعلی (۱۸ ملک) از تراکنش‌های واقعیِ DLD ساخته شده (توضیح کامل پایین)، ولی یه اسنپ‌شاته — خودکار آپدیت نمی‌شه. برای اضافه‌کردن ملک‌های جدید (مثلاً از یه آژانس یا اکسل خودت)، دو تا اندپوینت هست:

**از طریق CSV** (ساده‌ترین راه، اگه فقط اکسل داری):
```bash
curl -X POST "http://127.0.0.1:8000/v1/properties/import/csv?mode=replace" \
  -H "X-Admin-Token: <ADMIN_TOKEN شما>" \
  -F "file=@listings.csv"
```
فرمت CSV تو `backend/data/properties_template.csv` هست: ستون‌های `name,area,type,price_aed,size_sqft,roi_pct`.

**از طریق JSON** (برای یکپارچه‌سازی برنامه‌ای):
```bash
curl -X POST "http://127.0.0.1:8000/v1/properties/import?mode=append" \
  -H "X-Admin-Token: <ADMIN_TOKEN شما>" -H "Content-Type: application/json" \
  -d '[{"name":"...", "area":"...", "type":"...", "price_aed":1200000, "size_sqft":900, "roi_pct":6.5}]'
```

⚠️ قبل از دیپلوی عمومی، حتماً یه مقدار واقعی برای `ADMIN_TOKEN` ست کن (`export ADMIN_TOKEN=...` لوکال، یا Environment Variable روی Render) — وگرنه این اندپوینت‌ها با مقدار پیش‌فرض ناامن باز می‌مونن.

## منبع دیتای واقعی — چطور به‌دست اومد

اتصال مستقیم به دیتاست باز DLD (Dubai Pulse, `dubaipulse.gov.ae`) رو امتحان کردم — سرورشون از این محیط اتصال رو رد می‌کنه (به‌احتمال زیاد فیلتر IP غیر-امارات یا دیتاسنتر). به‌جاش، یه پروژه‌ی متن‌باز روی گیت‌هاب پیدا کردم ([GusCurrie/dubai-property-monitor](https://github.com/GusCurrie/dubai-property-monitor)) که یه دیتاست فشرده از تراکنش‌های واقعی DLD رو تو داشبورد استاتیک خودش embed کرده و روزانه آپدیت می‌کنه — این خودش از داده‌ی باز DLD می‌آد، پس مسیر غیرمستقیم ولی منبع نهایی یکیه.

از اون دیتاست (به‌روز تا ۲۱ سپتامبر ۲۰۲۶، حدود ۳۹هزار تراکنش فروشِ اخیر): برای ۱۸ منطقه‌ی واقعی و شناخته‌شده‌ی دبی (جمیرا ویلج سیرکل، بیزینس‌بی، دبی مارینا، برج خلیفه، آرجان، و…)، یه تراکنشِ نماینده انتخاب کردم، و برای هرکدوم:
- **روند ۶ ماهه‌ی قیمت** از میانگین وزنیِ قیمت-هر-فوت‌مربعِ واقعیِ همون منطقه/نوع ملک محاسبه شده
- **بازده اجاره (ROI)** از نسبت واقعیِ اجاره‌ی میانه به قیمت فروش میانه‌ی همون منطقه محاسبه شده (نه عدد ساختگی)

یعنی قیمت‌ها، متراژها و بازده‌ها همه از تراکنش‌های واقعاً ثبت‌شده می‌آن — نه نمونه‌ی دستی. محدودیت صادقانه‌ش: این یه **اسنپ‌شات** از یه لحظه‌ست (نه فید زنده)، و هرکدوم *یه معامله‌ی گذشته*ست، نه لیستینگ زنده‌ای که الان بشه خریدش.

## چیزی که هنوز محدودیت داره (شفاف بگیم)

- دیتای ملک‌ها اسنپ‌شاته، نه فید زنده — برای آپدیت باید دوباره اسکریپت استخراج رو اجرا کرد یا از endpoint های import بالا استفاده کرد.
- آستانه‌های ویزا تقریبی‌ان و باید قبل از استفاده‌ی واقعی با GDRFA/ICP یا مشاور مجاز چک بشن.
- مدل ارزیابی قیمت یه رگرسیون خطی روی روند واقعیِ قیمته، نه یه مدل ML آموزش‌دیده‌ی کامل — برای MVP کافیه.
- ترجمه‌ی انگلیسی، رابط و محتوای اصلی رو پوشش می‌ده؛ اسم پروژه‌های واقعی (مثل Serenz by Danube) همیشه انگلیسی نمایش داده می‌شن چون اسم خاصن. پاسخ‌های زنده‌ی چت به هر زبونی که کاربر تایپ کنه جواب می‌ده (چون از Claude واقعی استفاده می‌کنه).

هدف این نسخه اینه که یه *بک‌اند، فرانت‌اند و دیتای واقعیِ قابل‌تست* داشته باشی، نه یه ادعای توخالی — قدم بعدی، رشدشه.
